HIPZ — DIMA S7AB

Official Bilingual Brand Website — Algeria

YOUR ROLE

Act as a world-class creative director, premium beverage-brand designer, UX/UI specialist, and senior full-stack frontend engineer.

Your mission is to design and implement a complete, polished, production-ready official presentation website for HIPZ, a fruit-drink brand featuring two products:

- HIPZ Lemon — yellow packaging, lemon flavor.
- HIPZ Peach — orange packaging, peach flavor.

The official brand slogan is:

HIPZ — dima s7ab

This is a real-world presentation project intended to be shown to the brand's owner or management. The final result must demonstrate professional design quality, brand awareness, technical competence, and commercial value.

Do not build a generic corporate template. Create a distinctive beverage-brand experience that feels like a premium advertising campaign.

4. BILINGUAL ARCHITECTURE — CRITICAL

Implement a complete French/Arabic language switcher in the main navigation.

French must be the default language.

Display language options clearly, for example:

- FR
- العربية

When Arabic is selected:

1. Set the document language to Arabic.
2. Set the page direction to RTL.
3. Reverse directional navigation and layout where appropriate.
4. Align Arabic text correctly.
5. Adjust icons, arrows, menus, and breadcrumbs according to direction.
6. Keep product images and brand logos in their correct orientation.
7. Preserve the exact Latin spelling of HIPZ and “dima s7ab”.
8. Ensure all sections, forms, menus, and footer elements are translated.

When French is selected:

1. Set the document language to French.
2. Restore LTR layout.
3. Use natural French typography and punctuation.
4. Restore the French content throughout the entire site.

Implement a centralized translation dictionary or a well-structured i18n system. Never translate only the hero while leaving the rest of the page in the previous language.

Language switching must happen instantly without a full-page reload.

Suggested French hero:

Headline: “HIPZ. DIMA S7AB.”

Supporting text: “Deux saveurs. Une seule vibe.”

Primary CTA: “Découvrir nos saveurs”
